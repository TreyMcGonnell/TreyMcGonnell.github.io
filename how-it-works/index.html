How this works

The chat on the home page is a real language model, and the picture beside it is drawn from what happens inside it while it writes. Nothing in the picture is decoration.

The parts

This websiteStatic pages on GitHub Pages. Draws the city, the towers and the chat.
→
A small serverChecks limits, searches Trey's notes with Supermemory, and splits text into tokens.
→
The modelLlama 3.2 3B Instruct on a cloud GPU (Modal). It sleeps when nobody is asking, so the first question wakes it.

How one answer is made

  1. Your question becomes tokens. Models read pieces of words, not letters. Each token becomes a list of 3,072 numbers.
  2. Supermemory searches Trey's notes. The best-matching notes, at most three, are pasted into the prompt along with a short bio and a few rules. The model only knows about Trey what is in that prompt.
  3. The model reads the whole prompt at once. All of it passes through 28 layers in a single step, usually in well under a second. The page slows that step down so you can see it.
  4. It writes one token at a time. For each one it computes odds for every token it knows (128,256 of them), then picks one at random in proportion to those odds, at temperature 0.7. The top five are what you see as bars.

Reading the picture

Towers and windows

Each of the 28 towers is one layer of the model. Each window is one neuron: a single number inside the layer's feed-forward block. A layer has 8,192 of them; the page shows the same 14 per layer every time, picked in advance because they are often among the most active. Brightness shows how strongly a neuron is firing compared to its usual range.

quiet a little firing very strongly

The callout names the strongest of those windows. Its description ("lights up for words like …") is generated automatically from the words that excited that neuron most during testing, so treat it as a hint, not a definition.

Where it's looking

Attention is how a token pulls information from earlier tokens. The page averages attention from the newest token over all heads in layers 20 to 27 and groups it by part of the prompt: the rules, the bio, each note from Supermemory, your question, and its own answer so far. This is a strong hint about which source a word came from, not proof.

What each layer would have said

The "logit lens" runs the model's final step on earlier layers (4, 10, 16 and 22) to see what word they would have picked. Early guesses are often odd; they sharpen as the layers go on.

The replay

The replay on the home page is a recorded answer from this same model and the same notes, saved frame by frame. It plays while the model wakes up. Its timing is slowed into a 20-second story; the numbers in it are real.

Privacy and limits

Questions and answers are kept for 30 days to check quality, then deleted. IP addresses are never stored: rate limits use a salted hash that changes daily. Each visitor can ask 10 questions per 10 minutes and 60 per day, and the site has a daily total so it stays affordable.

The model can be wrong. It is told to answer only from Trey's notes and to say when it doesn't know, but a 3-billion-parameter model sometimes slips.
